ЛОГИКОН — включване на истински акаунти (Supabase)

1. Създайте безплатен проект на https://supabase.com/dashboard.
2. От Project Settings → API (или Connect) копирайте Project URL и publishable/anon ключ.
3. Попълнете url и anonKey в auth-config.js. НИКОГА не използвайте service_role или secret ключ в сайта.
4. Authentication → Providers → Email: активирайте Email. Препоръчително е да оставите включено потвърждение на имейла.
5. Authentication → URL Configuration: задайте реалния Site URL и позволените Redirect URLs за домейна на ЛОГИКОН.
6. Качете файловете на HTTPS хостинг. При локални тестове ползвайте локален HTTP сървър.
7. Настройте SMTP за реална публична употреба: стандартният имейл доставчик на Supabase има ограничения.
8. Настройте шаблоните за имейл и CAPTCHA/защита от злоупотреби преди публичен старт.

Важно: входът, регистрацията, изходът и изпращането на имейл за възстановяване работят след конфигурация. За реално задаване на НОВА парола след линка е необходим допълнителен recovery екран — текущата версия предоставя заявката за имейл, не целия процес.
Напредъкът в игрите все още е в localStorage на устройството, не се синхронизира с профила. За синхронизация е нужна база с RLS политики и отделна интеграция.
